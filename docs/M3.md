# M3 投递看板闭环

已完成。把一次预填记成投递卡片，在网页看板和扩展「投递」列表里看公司与进展。

预填不等于代投。提交按钮、验证码、登录框一律停下来等人；人提交后再把状态改成「已投」。

## 记什么

每张卡：公司、岗位、网申链接、简历版本、状态、缺项、备注。

状态：待投 → 已预填 → 已投 → 笔试 / 面试 → Offer / 挂。

同一网申链接再次预填会更新这张卡，不重复建卡。

## 怎么进看板

- 扩展或页面浮层点「确认写入」后，请求本机 `POST /applications/from-fill`。
- 公司名从页面标题 / 域名猜；不对就在看板里改。
- 网页 `/board` 也可以点「记一笔」手加。

## 扩展

弹窗有「预填 / 投递」两个页。投递列表显示公司、岗位、状态；亲手提交后点「我已提交」。

HTTPS 网申页的书签浮层可能被 CSP 拦住记卡；扩展弹窗不受这个限制。

## 明确不做

自动提交、自动过验证码、云端代投、导出 Cookie、Boss 海投当主功能。
